# כתר הנדסה — מערכת ניהול פרויקטים

מערכת ווב פנימית לניהול משימות, פרויקטים ולוחות זמנים עבור חברת ניהול ופיקוח
פרויקטי בנייה. נבנתה עם דגש על שיתוף פעולה בין שני השותפים בחברה.

## מה יש במערכת (v1)

- **התחברות** — חשבון אחד משותף לחברה (אימייל וסיסמה אחת), ואחרי ההתחברות
  כל אחד מהשותפים בוחר את השם שלו כדי לשייך אליו משימות ופעילות.
- **לוח בקרה** — סיכום כללי: משימות פתוחות ובאיחור, פרויקטים פעילים, עומס
  עבודה לפי שותף, מועדי יעד קרובים, פעילות אחרונה ופילוח פרויקטים לפי סטטוס.
- **משימות** — לוח קנבן משותף (לביצוע / בתהליך / לבדיקה / הושלם) עם גרירה
  ושחרור בין עמודות, סינון לפי אחראי/פרויקט/עדיפות, עריכה ומחיקה.
- **פרויקטים** — רשימת פרויקטים עם סטטוס, לקוח, כתובת ותקציב; דף פרויקט
  מפורט עם ציר זמן של אבני דרך והמשימות המשויכות אליו.

## הרצה מקומית

```bash
npm install
cp .env.example .env      # ואז לעדכן SESSION_SECRET לערך אקראי משלכם
npm run db:migrate        # יוצר את מסד הנתונים (SQLite) לפי הסכמה
npm run db:seed           # יוצר את חשבון ההתחברות המשותף + נתוני דוגמה
npm run dev
```

האתר יעלה בכתובת http://localhost:3000

### פרטי התחברות ראשוניים

לאחר ההרצה של `db:seed` נוצר חשבון התחברות משותף אחד:

| אימייל                     | סיסמה      |
| --------------------------- | ---------- |
| keterengineers@gmail.com    | keter2026! |

שני השותפים מתחברים עם אותו אימייל וסיסמה, ואז בוחרים במסך הבא איזה מהשניים
הם ("רון" או "גיא") — כדי שמשימות ופעילות ישויכו לאדם הנכון. אפשר להחליף
משתמש בכל רגע דרך "החלפת משתמש" בתפריט הצד, בלי להתחבר מחדש.

**מומלץ להחליף את הסיסמה בהקדם** — כרגע אין מסך ניהול הגדרות ב-UI, ולכן זה
נעשה דרך `npm run db:studio` (עורך מסד נתונים גרפי שנפתח בדפדפן, טבלת
`Credential`) או ישירות בקובץ `prisma/seed.ts` לפני ההרצה הראשונה.

## טכנולוגיה

Next.js 16 (App Router, TypeScript) · Tailwind CSS 4 · Prisma ORM · SQLite ·
אימות מבוסס עוגיית JWT (ללא ספריית auth חיצונית) · React Server Actions לכל
הפעולות (יצירה/עריכה/מחיקה) ללא צורך ב-API נפרד.

מסד הנתונים הוא קובץ SQLite מקומי (`prisma/dev.db`, לא נכלל ב-git). לפריסה
בסביבת ייצור מומלץ לעבור למסד PostgreSQL מנוהל (למשל Neon / Supabase /
Vercel Postgres) ולעדכן את `DATABASE_URL` ואת ה-`provider` ב-
`prisma/schema.prisma`.

## פריסה לאינטרנט

הדרך הפשוטה ביותר היא [Vercel](https://vercel.com): לחברו לריפו הזה, להגדיר
את משתני הסביבה (`DATABASE_URL`, `SESSION_SECRET`), ולעבור למסד PostgreSQL
מנוהל כאמור לעיל (SQLite לא מתאים לפריסה serverless).

## מבנה הפרויקט

```
prisma/schema.prisma       סכמת מסד הנתונים (Credential, User, Project, Milestone, Task, Activity)
prisma/seed.ts             נתוני התחלה: חשבון ההתחברות המשותף, 2 פרופילי השותפים + פרויקטי דוגמה
src/lib/auth.ts            זיהוי ה-session וה"שותף" הפעיל בכל בקשה
src/lib/session.ts         חתימה ואימות של עוגיית ה-session (JWT)
src/lib/actions/auth.ts    התחברות/התנתקות/בחירת שותף
src/lib/actions/*.ts       כל שאר הפעולות מול מסד הנתונים (Server Actions)
src/app/login               מסך התחברות עם חשבון החברה המשותף
src/app/choose-user          מסך בחירת השותף (רון / גיא) אחרי ההתחברות
src/app/(app)/*             העמודים המוגנים: לוח בקרה, משימות, פרויקטים
src/components/*            רכיבי UI
```

## רעיונות להמשך (לא כלול ב-v1)

- ניהול משתמשים דרך ה-UI (הוספת שותף/עובד נוסף, החלפת סיסמת החברה)
- תגובות/דיון על משימה ספציפית
- קבצים מצורפים למשימה/פרויקט (מסמכים, תמונות מהאתר)
- התראות מייל על משימות שעומדות להתאחר
